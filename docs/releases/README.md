# Turp release notes

Version-specific release notes live here so the repository root stays focused on the project overview and core documentation.

English source notes use `RELEASE_NOTES_<version>.md`. Turkish translations use `tr/RELEASE_NOTES_<version>.md`. The release pipeline combines both into each GitHub Release, while the Turp website shows the language matching the current English or Turkish page.

For a chronological summary, see the root [CHANGELOG.md](../../CHANGELOG.md). For downloadable APKs and checksums, use [GitHub Releases](https://github.com/omerfaruknehir/Turp/releases).
