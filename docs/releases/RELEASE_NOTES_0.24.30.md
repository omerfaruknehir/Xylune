# Turp 0.24.30

## Turp and Arbor themes

- Introduces Turp's proper radish-rooted Material palette with deep radish/crimson primary colors, leafy green secondary accents, warm root-toned tertiary accents, and coordinated light and dark surfaces.
- Preserves the previous green Turp palette as the new selectable **Arbor** theme instead of discarding it.
- Integrates Arbor across appearance settings, palette previews, launcher-theme matching, and dynamic launcher icon behavior.
- Updates GitHub Pages so Turp and Arbor are distinct selectable color schemes with matching previews and dynamic logo palettes.
- Adds regression coverage for the Turp/Arbor palette split and updates website integration tests accordingly.
